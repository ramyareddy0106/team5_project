# 👟 Lacely — Your Step, Your Style

Welcome to **Lacely**, a sleek and stylish e-commerce website built for a modern shoe brand. Designed with fashion-forward shoppers in mind, Lacely offers a smooth and responsive user experience that makes browsing and buying shoes simple and enjoyable.

---

## ✨ Features

- **Multi-page website** with separate sections for:
  - Men’s Collection
  - Women’s Collection
  - Kids’ Collection
- **User Authentication Redirect** — prompts login when a product is added to cart
- **Responsive Design** — works perfectly on mobile, tablet, and desktop

---

## 🎨 Front-End Stack

- **HTML5**
- **CSS3**
- **JavaScript**
- **Google Fonts** for enhanced typography

---

## 👩‍💻 My Role — Frontend Developer

As the **Frontend Developer**, I was responsible for:

- Designing the **layout and structure** of all web pages
- Creating **interactive elements** such as buttons, product cards, hover effects, and animations
- Integrating **login redirection logic** when users try to add products without signing in
- Coordinating with back-end team members to align UI with functionality
